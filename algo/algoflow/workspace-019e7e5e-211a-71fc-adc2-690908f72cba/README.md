# AlgoFlow

AlgoFlow is a local-first competitive programming toolkit that combines:

- unified backend (`algoflow-deploy`)
- browser scraping extension (`algoflow-extension`)
- sandbox runner (`algoflow-sandbox`)
- whiteboard sync (`algoflow-whiteboard`)
- spaced repetition logic (`algoflow-srs`)

## Quick start

```bash
cd algoflow-deploy
npm install
npm start
```

Open the URL printed in the terminal (usually `http://127.0.0.1:3001`).

## Load extension

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select `algoflow-extension/`
